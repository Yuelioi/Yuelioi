# Profile artwork

- `header.svg`: generated with [capsule-render](https://github.com/kyechan99/capsule-render), using its Venom template and a cyan / violet / pink gradient. Its MIT license is included.
- `typing.svg`: generated with [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg), showing `EL PSY KONGROO`. Its MIT license is included.
- `skills.svg`: generated by [Skill Icons](https://github.com/tandpfun/skill-icons), preserving the profile's existing Go, Rust, Vue, Astro, Python and TypeScript choices. Its MIT license is included.
- `bilibili.svg`: generated by [Shields.io](https://shields.io) for the existing Bilibili account.
- The SVGs in `../profile-3d-contrib/` were generated from Yuelioi's actual GitHub contribution data using [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib). Its MIT license is included as `profile-3d-contrib-LICENSE.txt`.

The four decorative images are stored in this repository. The contribution city is scheduled to regenerate daily after publication, using the GitHub Actions token. This workflow commits only the two displayed SVGs to `main`. The existing snake keeps using its `output` branch.
